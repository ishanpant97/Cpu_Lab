📚 8086 & Simulator Instruction Reference

Data Transfer Instructions

MOV dst, src — Transfer data between registers, memory, or immediate.

XCHG dst, src — Exchange contents of two registers or register & memory.

PUSH src / POP dst — Push 16-bit word onto stack (decrements SP by 2) / Pop from stack.

LEA reg, [mem] — Load Effective Address into register (e.g. LEA BX, [SI+4]).

Arithmetic & Logic

ADD / SUB dst, src — Add / Subtract with flags (ZF, SF, CF, OF, PF) updated.

MUL / DIV src — Unsigned 16-bit multiplication (DX:AX ← AX * src) / division.

INC / DEC dst — Increment / Decrement by 1 (leaves Carry Flag CF unchanged).

AND / OR / XOR / NOT dst, src — Bitwise logic operations.

CMP dst, src — Compare operands by subtracting (updates flags, preserves dst).

TEST dst, src — Bitwise AND test (updates ZF, SF, PF; clears CF, OF).

SHL / SHR dst, count — Shift Left / Right by count or CL.

Control Flow & Stack

JMP label — Unconditional jump.

JE / JZ, JNE / JNZ — Jump if Equal (Zero flag = 1) / Not Equal (Zero flag = 0).

JG, JGE, JL, JLE — Signed conditional jumps (Greater, Less, etc.).

JA, JAE, JB, JBE — Unsigned conditional jumps (Above, Below, Carry).

CALL label / RET — Subroutine call (pushes return IP to stack) / return.

LOOP label — Decrement CX, jump if CX ≠ 0.

HLT — Halt processor execution.

Addressing Modes

Supports direct offsets [0x10], [10h], registers [BX], displacements [BX+4], [SI-2], and based-indexed [BX+SI+disp].
